# 决策索引

> 本文件记录**为什么这么定**，以及当前有效的口径。它不是需求文档，需求见 `SPEC.md`。
>
> 只增不改：已失效的条目不要删除，改为标注「已废止」。

## 使用说明

每条记录包含三个要素：

- **日期**：没有日期，三个月后无法判断新旧。
- **原因**：只写结论等于没有记忆，下次还会被推翻。
- **影响与关联**：让别人知道这条决策会碰到哪些代码或文档。

```markdown
- <YYYY-MM-DD>：<决策内容>。
  原因：<为什么这么定>。
  影响：<会碰到哪些模块 / 需要注意什么>。
  关联：<SPEC.md#锚点 或 spec/目录名>
```
