# 需求原始输入留档

本目录存放**一次需求的原始输入**，用于事后追溯「当初到底要的是什么」。

## 命名

`<YYYYMMDD>-<主题>.md`，例如 `20260924-客户列表团队筛选.md`。

用脚本创建可自动带上日期：

```bash
node scripts/new-spec.mjs --title "客户列表团队筛选"
```

## 内容模板

```markdown
# <主题>

- 提出人 / 日期：
- 关联需求：SPEC.md#<锚点>
- 原始描述：
- 要什么：
- 不要什么（范围外）：
- 待确认项（谁确认）：
```

## 规则

1. 保留**原始措辞**，不要润色。润色过的需求会丢失原始意图。
2. 需求变化时改 `SPEC.md`，**不要回改本目录的文件**。
3. 需求被推翻时，在文件顶部加一行：`> 状态：已废止（原因、日期）`。
4. 一个需求一个文件；超过 200 行说明该拆成多个需求。
5. 主题命名与 `docs/verification/` 下的证据目录保持一致，便于互相查找。
