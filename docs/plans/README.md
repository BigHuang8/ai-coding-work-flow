# 实施计划留档

本目录存放**实施计划**，对应流水线第 ② 阶段的产出之一。与设计稿的区别：设计回答「怎么改」，计划回答「按什么顺序改、怎么验证」。

## 命名

`<YYYYMMDD>-<主题>-计划.md`，与 `spec/`、`docs/designs/` 保持一致。

## 模板

- 执行人 / 日期：
- 预计工作量：

## 使用建议

- **任务拆分粒度到文件**：多人（含多个 AI 会话）并行时，这一步决定会不会互相覆盖。
- **每条任务都要有完成判据**：写不出判据说明任务还不够具体。
- **计划是活的**：执行中发现偏差，直接更新本文件并说明原因，不要另开一份新计划。
