# 验收证据

本目录存放**可复现的验收证据**。规范见 `docs/06-验收与证据留档.md`。

## 目录结构

```text
docs/verification/<YYYYMMDD>-<主题>/
├── 验收报告.md      结论与逐条对照
├── 命令记录.md      实际执行的命令与原始输出
└── assets/          截图、录屏、导出文件
```

主体内容由 `node scripts/new-spec.mjs --title "<主题>" --with-verification` 生成骨架。

## 三条底线

1. **可复现**：换一个人按文档操作，能得到同样结果。
2. **原始**：保留命令与真实输出，包括失败。
3. **可定位**：标明版本、环境、数据前提。

## 禁止

- 只写「已完成，测试通过」而不附命令与输出。
- 截图包含真实用户数据（手机号、身份证号、真实姓名）。
- 命令记录里出现未脱敏的 Token 与口令。

## 保留期限

建议长期保留，回溯成本极低。确认无价值时移入 `docs/verification/archive/`，不要直接删除。
