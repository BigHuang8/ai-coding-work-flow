哪些东西永远别提交

零入库，不接受例外
1.零入库
口令 · 密钥 · Token
数据库口令、API Key、签名密钥、盐值
证书私钥、真实用户数据、生产连接串
2.配置放哪
.env.example 只放占位符
真实口令写进 .env，由 .gitignore 排除
文档里写「向维护者索取」，不写默认口令
3.提交前三问
别指望扫描器
有没有出现「看起来像真的」密钥？
有没有贴 .env 内容？截图是否脱敏？
4.泄漏了怎么办
先轮换，再清理
删文件不能撤销泄漏，历史提交还在
轮换 → 查范围 → 清历史 → 记录 → 补门禁
5.AI 边界
少授权，多自查
不给 AI 生产环境权限，不喂敏感数据
新增依赖必须评审并锁定版本与来源
红线与应急步骤见 docs/07-安全与密钥.md
