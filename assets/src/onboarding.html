接入一个已有项目

老项目照样能接，只补不改
1.先体检
node scripts/detect-stack.mjs
只看不改：项目实际用了哪些栈
输出三类清单：已启用 / 装箱 / 缺口
2.先预览
bootstrap.mjs --dry-run
列出将写入的文件，一个字节都不落盘
已存在的文件一律跳过，不覆盖
3.再注入
bootstrap.mjs --target
写两份记录：docs/TECH_STACK.md
和 workflow.config.json，供脚本消费
4.融合清单
AI 入口 · CI · 钩子 · validate
自有 CLAUDE.md 先并入 AGENTS.md
再由同步脚本重新生成，避免两份漂移
5.认领缺口
负责人 + 期限
写进 docs/TECH_STACK.md 第三节
没人认领的缺口，等于这个项目没接入
6.验收
一个月后切 --strict
npm run validate 全绿
一个月后缺口从警告升级为拦截
完整步骤见 docs/08-接入清单.md 与 docs/10-技术栈适配.md
